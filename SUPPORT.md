# Support

RAE is a public alpha candidate and does not currently provide commercial or
guaranteed support.

Before opening an issue:

1. Run `./scripts/rae.sh doctor`.
2. Check the relevant package README and [documentation index](docs/INDEX.md).
3. Search existing issues.
4. Remove secrets, credentials, and private machine paths from logs.

Use the matching repository issue form for reproducible bugs, bounded feature
requests, or documentation improvements. Include the command, expected
behavior, actual behavior, operating system, and runtime versions where they
apply.

Do not report vulnerabilities in public issues. Follow the private reporting
instructions in [SECURITY.md](SECURITY.md).
