The loopback operator turns local run state into a review surface. This tour shows the workflow editor against sanitized fixture data. It is a static capture, not evidence from a live run.

Open the interactive demo

Workflow editor: desktop

Author and validate revision-controlled workflows. The registry pins an active revision and digest, the graph shows node tiers and access, and the inspector exposes budgets, loop bounds, quorum, and gate flags.

The interactive demo is a real browser surface using the same static UI, but its data, API responses, and mutations live only in the browser. It has no repository or filesystem access, makes no backend calls, and exposes no live or publish controls. The full operator is bearer-authenticated, same-origin, and loopback-only.
