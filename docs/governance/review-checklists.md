# Review Checklists

## Documentation review

- mode is correct for the page type
- source of truth is explicit
- evidence links are present and still relevant
- dossier links are present for major cross-page claims
- formal pages define terms and assumptions before derivations
- notation matches [Notation](../explanation/supplementary/notation.md) or
  declares a local deviation explicitly
- formulas render correctly and match the surrounding prose
- citations resolve to the bibliography or the owning internal source surface
- the page includes at least seven relevant external sources
- claims are not stronger than the supporting evidence
- uncertainty and interpretation limits are explicit where evidence is partial
- outdated statements are corrected or downgraded

## Release review

- verification output is recent
- repo citation metadata still reflects the published repository identity
- claim-bearing docs were reviewed for drift and citation completeness
- imported modules still match documented boundaries
- examples still reflect the command surfaces they describe

## Scholarship audit

- proof mode is stated or inferable from the page structure
- source packet fits the page type rather than padding it with weak citations
- limitations or validity threats are explicit
- major theses resolve to a stable claim dossier
- internal anchors remain stronger than prose when the page describes local
  behavior
