# Design Axioms

These are working axioms for the umbrella, not claims of universal optimality.

## Axiom 1

Prefer the smallest execution structure that preserves quality and auditability.

## Axiom 2

Make evidence production part of system design, not an afterthought added after
implementation.

## Axiom 3

Keep destructive or maintenance-only tools outside the conceptual center of the
runtime architecture.

## Axiom 4

Treat documentation as a control surface that changes operator behavior and
therefore affects system reliability.

## Axiom 5

Preserve boundaries between artifact structure, gate decisions, and publication
claims.
