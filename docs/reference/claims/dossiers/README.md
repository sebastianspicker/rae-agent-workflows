# Claim Dossiers

This directory holds thesis-level proof packets for major RAE claims. A dossier
is the stable home for:

- the precise claim statement
- claim class and proof mode
- assumptions and boundary conditions
- strongest internal anchors
- strongest external anchors
- benchmark artifacts where applicable
- counterarguments, validity threats, and review status

Science, governance, and research pages should link here when a claim spans more
than one article.
