# Code of Conduct

## Commitment

RAE is an evidence-focused engineering project. Participation should remain
welcoming, professional, and safe regardless of experience, identity, or
background.

## Expected behavior

- Discuss ideas and code without attacking people.
- Give specific, reproducible, and actionable technical feedback.
- Acknowledge uncertainty and correct mistakes openly.
- Protect private reports, credentials, and personal information.
- Respect maintainer decisions about scope, safety, and release timing.

## Unacceptable behavior

Harassment, discriminatory language, threats, doxxing, sustained disruption,
and publication of private reports or credentials are not accepted.

## Scope and enforcement

This policy applies to repository issues, pull requests, reviews, discussions,
and project-related communication. For conduct on GitHub, use GitHub's
[content-reporting controls](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Do not put personal information in a public issue. This repository does not yet
publish a project-specific private conduct-reporting address; configuring one
is a public alpha release blocker. Reports may lead to a warning, removal of
content, temporary restriction, or permanent exclusion from project spaces.

Security vulnerabilities follow [SECURITY.md](SECURITY.md), not the conduct
reporting route.
